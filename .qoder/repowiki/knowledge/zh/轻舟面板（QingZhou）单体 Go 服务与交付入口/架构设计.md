根目录是 QingZhou 面板的 Go 单体应用：main.go 启动时依次加载 config → 打开并迁移 SQLite（modernc.org/sqlite，无 CGO）→ 初始化管理员种子与 JWT secret → 构建 SMTP mailer → 创建 api.API 实例并注入 store/jwt/mailer → 启动原生 sing-box 控制器（本地 sbproc + SSH 远程 sshctl，统一通过 sbctl.Controller 管理远端落地节点）→ 注册后台协程（SourceSync/Maintenance/MonitorTasks/CertRenew/QueueAdvance）→ 启动 chi HTTP 服务器监听 QZ_LISTEN。Dockerfile 采用三阶段构建：先 node:20 编译 frontend/dist，再 golang:1.25 交叉编译 qingzhou 二进制与 cmd/probe（amd64/arm64），最后用 alpine 运行；docker-compose.yml 提供一键部署模板，暴露 8081 端口并以命名卷持久化 /data/qingzhou.db。前端 SPA 由 Vite 构建后通过 //go:embed 嵌入二进制，由后端直接分发，因此前后端共享同一进程与 /api、/sub 契约。
