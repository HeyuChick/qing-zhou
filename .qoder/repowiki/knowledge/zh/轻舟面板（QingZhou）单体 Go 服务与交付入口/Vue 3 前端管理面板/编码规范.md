- 所有 HTTP 请求统一通过 `@/api` 提供的 `apiGet/apiPost/apiPut/apiDelete/apiList` 发起，禁止在组件中直接使用 fetch 调用后端接口。
- 路由权限控制通过在路由元信息上标注 `requiresAuth` / `requiresAdmin`，由 `router.beforeEach` 统一拦截并跳转，而非在各视图中自行判断登录态。
- Pinia store 使用 Composition API 风格的 `defineStore` 定义，将响应式状态（ref）与方法一并 return，并通过 computed 派生派生属性（如 `isLoggedIn`、`isAdmin`）。
- 视图组件按角色前缀命名（`User*`、`Admin*`），并以 `DashboardLayout.vue` 作为共享布局容器，子路由通过懒加载 `() => import(...)` 注册。
- API 响应统一遵循 `{code,data,msg}` 信封格式，封装层自动解包 `.data`，仅对返回原始 JSON 文档的特殊接口使用 `apiGetRaw`。
- Token 持久化在 `localStorage` 的 `qz_token` 键中，并在每次请求时通过 `Authorization: Bearer <token>` 头携带，401 时自动清理状态并跳转登录。
