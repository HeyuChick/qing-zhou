模块以 `src/main.ts` 为入口创建 Vue 应用并挂载 Pinia 与 vue-router；路由采用 `createWebHashHistory`，将 `/` 作为公开监控页，`/dashboard`~`/account` 为用户端页面，`/admin/*` 为管理员页面，并通过 `meta.requiresAuth` / `requiresAdmin` 在 `beforeEach` 守卫中统一鉴权。

- 视图层：`views/` 下按角色划分（User* 与 Admin*），共用 `components/DashboardLayout.vue` 作为带侧边栏的布局壳；通用 UI 组件集中在 `components/`（登录弹窗、退款弹窗、统计卡片、图表等）。
- 状态层：`stores/auth.ts` 管理 token、用户信息与登录态，`stores/config.ts` 拉取站点配置；均使用 Pinia Composition API 风格 store。
- 网络层：`api/index.ts` 提供统一的 `request` 封装，自动注入 Bearer Token、处理 401 登出跳转、解包 `{code,data,msg}` 信封，并提供 `apiList/apiGet/apiPost/apiPut/apiDelete/apiDownload` 等便捷方法。
- 工具层：`utils/` 提供格式化、Markdown 渲染、剪贴板、数字动画等无状态函数。
- 构建与部署：Vite 配置 (`vite.config.ts`) 设置 `@` 别名、开发代理到 `http://127.0.0.1:8081`，产物输出至 `dist/`；根目录 `embed.go` 通过 `//go:embed all:dist` 将静态资源内嵌进 Go 二进制，并在 `QZ_WEB_DIR` 环境变量存在时回退到磁盘直读，实现开发与生产统一的前端服务。
