# 订阅使用指南

## 一、拿到订阅链接

登录后在「**订阅管理**」复制订阅链接。**同一条链接通用所有客户端**——
服务器会根据你的客户端自动返回对应格式，无需手动选。

## 二、各客户端导入

| 客户端 | 平台 | 导入方式 |
|---|---|---|
| **mihomo / Clash Verge / ClashX Meta / Stash** | 全平台 | 配置订阅里粘贴链接，自动得到 Clash 配置 |
| **sing-box 官方客户端（SFA / SFI / SFM / SFT）** | 全平台 | 新建「远程配置」粘贴链接 |
| **Surge** | iOS/Mac | 作为「托管配置」导入（部分协议不支持，见下） |
| **v2rayN / NekoBox / Shadowrocket / Quantumult X** | 各平台 | 粘贴链接即可（base64 通用格式） |

> 想强制某种格式，可在链接后加 `?format=clash` / `?format=singbox` / `?format=surge`。
> Surge 不支持 VLESS / Reality / TUIC，这类节点会被跳过。

> ⚠️ **用 sing-box 格式的话，客户端版本要 ≥ 1.12。** 订阅用的是 1.12 引入的 DNS 写法，
> 而 1.14 已经**移除**了更老的写法——版本太旧的客户端导入后会**直接加载失败**（不是告警），
> 报错通常指向 `dns` 或 `route` 段。升级客户端即可。Clash / Surge / base64 订阅不受此限制。

## 三、智能优选（自动选最快）

导入后你会看到几个**自动选择组**：

- **♻️ 自动选择**：在你所有节点里自动测速、选最快的（IP 和协议都可能变）。日常挂这个即可。
- **⚡ <服务器IP>**：当一台服务器同时提供多种协议时，这个组会**固定该 IP、只在协议间选最快**
  （比如同一台机的 vless / hysteria2 之间自动挑）。适合想锁定某条线路的人。
- **✈️ 节点选择**：总开关，可手动指定上面任意自动组或某个具体节点。

## 四、代理范围与自带分流

复制订阅前可以选择代理范围：

- **智能分流（推荐）**：AI 服务固定走 AI 节点；中国大陆网站/IP 直连；其余公网流量走代理。
- **全部代理**：AI 和所有公网流量都走代理，仅局域网保持直连。

这个选择会写进新复制的订阅 URL，只影响使用该 URL 重新导入的客户端。升级前已经导入、
且 URL 中没有 `profile` 参数的订阅继续保持原来的配置，不会被自动切换。

智能分流不只是添加 CN 路由：Clash 会同时给 CN 域名选择国内加密 DNS，并在 DIRECT
出口解析真实地址；sing-box 使用配置内置的 `local` 直连解析器。AI 规则始终排在 CN
规则之前，防止 AI 请求因地域规则意外直连。Surge 按自身机制在 DIRECT 时使用本地 DNS，
代理请求仍把域名交给代理端解析。

Clash 端依赖 GEO 数据；sing-box 首次会通过代理下载 CN/广告/AI 规则集。通用 base64
格式只包含节点，无法携带服务端分流策略，代理范围由 v2rayN、Shadowrocket 等客户端的
本地配置决定。

## 五、节点管理（在面板里）

在「**订阅管理**」页往下就是节点列表（**按套餐分组**，并标出每个节点的中转 / 出口链路），可以：

- 搜索 / 按协议、分组、延迟筛选；
- 测速后用「**条件启用**」自动只留延迟在某区间的节点；
- 一键禁用所有不可用节点（只对你自己生效）；
- 勾选批量启用/禁用。被禁用的节点不会出现在订阅里。

> 早期版本这块是独立的「我的节点」页，现已并入「订阅管理」，不必再去别处找。

## 六、HTTP / SOCKS5 代理账号（如管理员开了）

如果管理员建了 **mixed 类型**的节点，「订阅管理」页会多出一张 **HTTP / SOCKS5 代理** 卡片。它**不在订阅链接里**，用于填进只认 HTTP/SOCKS 代理的地方（1Panel「代理服务器」、Docker、git、各类命令行工具）：

- 卡片直接给出**地址 / 端口 / 用户名 / 密码**，按需复制填入即可；显示「HTTPS 代理」时在客户端选 HTTPS，否则选 HTTP 或 SOCKS5。
- 也可**一键复制成完整 URL**（`http://用户名:密码@地址:端口` 形式），直接粘给浏览器插件、`curl -x`、`git config http.proxy`、`HTTPS_PROXY` 环境变量等，省去一格格填。
- 这是一组**独立的代理账号**，与登录账号无关；可在此**自定义用户名/密码**，泄露了随时改，也可设单独的到期时间。

## 七、订阅链接泄露了怎么办

「订阅管理」页有**两个不同的操作**，别搞混：

| 操作 | 效果 | 什么时候用 |
|---|---|---|
| **更换订阅地址** | 换一条新的订阅 URL，节点账号密码不变 | 只是链接被别人看到，想让旧链接失效 |
| **重置节点凭据** | 轮换各节点的用户凭据，已导入的客户端全部需要重新拉取 | 怀疑节点账号本身泄露了 |

> 早期版本这两件事是绑在一起的——那时「重置订阅链接」并不轮换节点凭据，**旧链接换汤不换药、拿到过的人照样能连**。现在拆成两个独立操作，按需要选。

## 八、常见问题

- **导入后节点很少？** 你的套餐/免费分组决定可见节点；换套餐或联系管理员。
- **sing-box 客户端导入报错 / 加载失败？** 客户端版本太旧，需 **≥ 1.12**，升级即可（见第二节的说明）。
- **Surge 里节点不全？** Surge 不支持 VLESS/Reality，属正常；建议 iOS 用 sing-box / Shadowrocket。
- **更新订阅不变？** 客户端有缓存，手动「更新订阅」；面板建议更新间隔 12 小时。
- **买了两份同样的套餐，怎么没叠加？** 同一套餐重复购买是**排队生效**：一次只跑一份，当前份流量用完或到期后下一份自动顶上，届时才开始算它的有效期——所以有效期不会在还没轮到时白白流逝。买不同套餐则同时生效、各自独立。
- **流量/到期** 在「订阅管理」和「控制台」可查——都按**套餐**分开列，每份套餐有自己的流量和到期，不是一个总数。
