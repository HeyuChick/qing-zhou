用户端

第一部分 · 用户端使用教程

面向普通使用者：注册、买套餐、拿订阅、导入客户端连上代理。演示账号 demo / demo12345。

1. 打开首页

面板首页是一块实时状态大屏，展示各节点的在线数与 CPU / 内存 / 上下行负载。首次使用点右上角「登录」。

截图：pub-home.png

2. 注册账号

在弹窗切到「注册」，填写用户名、邮箱、密码即可。若站点开启邀请注册，还需填写管理员发放的注册码。

  • 登录 / 注册 / 找回密码 三合一弹窗
  • 开放注册可直接注册；邀请制需注册码
截图：pub-login.png

3. 控制台总览

登录后进入控制台：最新公告、流量环形图、剩余流量 / 到期时间 / 积分，以及叠加显示的「我的套餐」。

  • 一眼看清剩余流量、到期时间与积分
  • 「我的套餐」把名下所有套餐叠加展示
截图：user-dashboard.png

4. 积分商城买套餐

用积分购买套餐，每张卡写清流量、有效期、设备数与价格。当前套餐仍在用时再买同类会「排队」，用完自动启用；「流量加油包」则直接给当前套餐加流量。

  • 计划类套餐可排队，不浪费
  • 流量加油包只加流量、不改到期
截图：user-shop.png

5. 订阅管理：拿订阅链接

核心页面。复制专属订阅链接，或点「显示二维码」扫码；按客户端选择 Clash / sing-box / Surge / 通用 格式；下方可自由启用禁用节点、一键测速。链接泄露点「重置链接」作废旧链接。

  • 复制订阅链接 / 扫码导入
  • 一键切换客户端格式
  • 节点可单独启停、测速；可重置链接
截图：user-sub.png

6. 帮助中心：客户端导入教程

面板内置图文教程。拿到订阅链接后回到客户端：Clash「从 URL 导入」粘贴链接→更新→选节点→开启系统代理；安卓 v2rayN 类「从剪贴板导入订阅」。

  • Clash：配置→从 URL 导入→更新→选节点→开代理
  • 安卓：v2rayN/v2rayNG 从剪贴板导入订阅
截图：user-help.png

7. 订单记录

查看历史购买订单与状态。

截图：user-orders.png

8. 积分明细

积分充值与消费的完整流水。

截图：user-points.png

9. 公告通知

查看站点公告，可标记已读。

截图：user-notices.png

10. 账户设置

修改密码、绑定 / 验证邮箱、查看并注销登录设备。

截图：user-account.png
管理端

第二部分 · 管理端配置教程

面向站长 / 运维：节点、套餐、线路、证书、多机与设置。演示账号 admin / admin12345，左下角展开「管理后台」。

1. 管理概览

运营总览：用户规模、流量消耗、收入趋势与分布图表。

截图：admin-overview.png

2. 节点管理

手动新建节点或粘贴外部订阅批量导入。关键概念是「节点分组」——把节点归入「高级线路 / 标准线路」等分组，套餐再按分组授权，从而精确控制「买了哪个套餐能用哪些节点」。

  • 自建 / 外部两类节点
  • 外部订阅源可自动拉取
  • 节点分组 = 授权的最小单位
截图：admin-nodes.png

3. sing-box 核心：出口与多级中转

五个标签：TLS 配置（证书 / Reality）、入站（对外监听）、代理出口（流量落地）、链路拓扑（把入站→中转→出口串成多级中转）、配置预览（生成并校验）。

  • 代理出口 = 流量最终从哪落地
  • 链路拓扑 = 多级中转编排
  • 改完在「配置预览」一键校验
截图：admin-singbox.png

4. 套餐管理

新建套餐时两条最关键绑定：①「可用节点分组」决定买了能用哪些节点；②「可购买用户组」决定谁能买（留空=对所有人公开）。设置积分价、有效期、库存后上架售卖。

  • 绑定节点分组（能用哪些节点）
  • 限定可购买用户组（谁能买）
  • 定价 / 库存 / 排序 / 上下架
截图：admin-packages.png

5. 用户管理

新建用户、充值积分，或直接「分配套餐」做免费手动开通；可查看某用户的订单与套餐。

截图：admin-users.png

6. 用户组

与套餐配合做分层销售：某些套餐只对特定用户组开放购买。

截图：admin-user-groups.png

7. 订单管理

查看全部订单，支持退款预览与退款处理。

截图：admin-orders.png

8. 注册码

邀请制注册时批量生成邀请码，即用户注册环节所填的注册码来源。

截图：admin-reg-codes.png

9. 证书中心

节点走 TLS 需要证书。支持 ACME + Cloudflare DNS-01 自动签发、粘贴导入、自签、到期自动续期。用 Cloudflare 需一个具备 DNS 编辑权限的 API Token。

  • ACME + Cloudflare DNS 一键签发
  • 自动续期 / 导出
截图：admin-certs.png

10. 服务器（多机编排）

通过 SSH 纳管多台落地机，测试连接、一键下发并重建 sing-box。

截图：admin-servers.png

11. 监控管理

汇总各机探针数据：CPU / 内存 / 带宽热力图与告警，超阈值自动提醒。

截图：admin-monitor.png

12. 系统设置

全局开关：注册模式（开放 / 注册码 / 关闭）与邮箱验证、订阅模板（自定义 Clash 规则）、SMTP 邮件、退款策略、面板公开地址、告警阈值。

  • 注册模式 + 邮箱验证
  • 订阅模板自定义（改过会永久覆盖内置默认）
  • SMTP / 退款策略 / 首页
截图：admin-settings.png

13. 在线更新

对接 GitHub Release，检查新版并一键自更新，无需登录服务器。

截图：admin-update.png

14. 公告管理

发布 / 置顶站点公告，展示在用户端控制台与「公告通知」。

截图：admin-announcements.png

15. 帮助文档

维护用户端「帮助中心」的图文教程，如各客户端导入指南。

截图：admin-help.png
