# 第一部分：用户端使用教程（约 2.5–3 分钟）

## 场景 1 · 打开首页，认识轻舟（约 12s）
- **截图**：`pub-home.png`
- **画面**：浏览器打开面板首页「服务器监控」大屏，顶部导航含「登录」。
- **操作**：地址栏输入面板地址回车 → 停留在首页监控大屏，鼠标缓慢划过顶部指标卡（服务器/CPU/内存/上下行）。
- **口播**：「打开面板首页，就是一块实时状态大屏，能看到各节点的在线与负载情况。第一次使用，点右上角『登录』。」
- **字幕**：首页 = 实时状态大屏
- **时长**：12s

## 场景 2 · 注册账号（约 20s）
- **截图**：`pub-login.png`
- **画面**：登录弹窗，含「登录 / 注册 / 找回密码」三个 Tab。
- **操作**：点「登录」按钮 → 弹窗出现 → 切到「注册」Tab → 依次填用户名、邮箱、密码（如开启注册码，展示填写注册码）→ 点「注册」。
- **口播**：「在弹窗里切到『注册』，填写用户名、邮箱和密码即可。如果站点开启了『邀请注册』，还需要填一个注册码——注册码由管理员发放。」
- **字幕**：注册 → 用户名 / 邮箱 / 密码（+注册码可选）
- **时长**：20s
- **备注**：录制前在管理端把「注册模式」设为『开放』或『注册码』，见管理端场景 16。

## 场景 3 · 登录后的控制台总览（约 20s）
- **截图**：`user-dashboard.png`
- **画面**：控制台——最新公告、流量环形图、剩余流量 / 到期时间 / 积分四个卡片、「我的套餐」列表。
- **操作**：登录后自动进入「控制台」，鼠标依次指向：流量环 → 剩余流量 110GB → 到期时间 → 积分 5000 → 下方「我的套餐」两条（注册赠送 + 月享套餐，均「使用中」）。
- **口播**：「登录后进入控制台。这里一眼看清：你还剩多少流量、什么时候到期、有多少积分。下方『我的套餐』会把你名下所有套餐叠加显示，都在正常使用中。」
- **字幕**：控制台 = 我的流量 / 到期 / 积分 / 套餐
- **时长**：20s

## 场景 4 · 积分商城买套餐（约 30s）
- **截图**：`user-shop.png`
- **画面**：积分商城，顶部「当前积分 5000」，5 张套餐卡（体验/月享/季度/年度/流量加油包），每张列出流量、有效期、设备数与积分价。
- **操作**：左侧点「积分商城」→ 浏览套餐卡 → 指向「季度套餐 2700 积分」→ 点「购买」→（弹出确认框）→ 确认 → 提示购买成功，积分扣减。
- **口播**：「想升级？到『积分商城』。每个套餐都写清了流量、有效期和可用设备数，用积分购买。注意——如果你当前套餐还在用，再买同类套餐会自动『排队』，等这一份用完再启用，不浪费。买『流量加油包』则是给当前套餐直接加流量。」
- **字幕**：积分商城 → 选套餐 → 购买（可排队 / 可加流量）
- **时长**：30s

## 场景 5 · 订阅管理：拿到订阅链接（约 30s）
- **截图**：`user-sub.png`
- **画面**：订阅管理——总流量进度、「我的计划」、**订阅链接 + 复制按钮**、客户端按钮（Clash / sing-box / Surge / 通用 v2rayN / 显示二维码 / 重置链接）、下方节点列表（HK01、SG01…）。
- **操作**：左侧点「订阅管理」→ 指向订阅链接输入框 → 点「复制」（提示已复制）→ 点「显示二维码」展示二维码 → 指向客户端按钮行 → 指向节点列表的「启用/禁用」和「测速」。
- **口播**：「核心就在『订阅管理』。这串就是你的专属订阅链接，点『复制』；手机用户点『显示二维码』扫码更方便。上面这排按钮，对应不同客户端的一键导入格式。下面是节点列表，你可以自由启用/禁用某条线路，也能一键测速。链接泄露了？点『重置链接』即可作废旧链接。」
- **字幕**：订阅管理 → 复制订阅链接 / 扫码 / 选客户端格式
- **时长**：30s

## 场景 6 · 导入客户端，连上代理（约 40s）
- **截图**：`user-help.png`（教程文案）+ 你本机客户端软件画面（Clash Verge / v2rayN / v2rayNG）
- **画面**：切到真实客户端软件。
- **操作（Clash 为例）**：打开 Clash → 「配置 / Profiles」→ 「从 URL 导入」→ 粘贴订阅链接 → 更新 → 在节点列表选一个节点 → 打开「系统代理」→ 打开网页验证已连通。
- **操作（安卓 v2rayN/v2rayNG 为例）**：右上角 `+` → 「从剪贴板导入订阅」→ 更新订阅 → 选节点 → 点连接。
- **口播**：「拿到链接后，回到你的客户端。以 Clash 为例：配置 → 从 URL 导入 → 粘贴链接 → 更新，就能看到所有节点，选一个、开启系统代理，就连上了。安卓用 v2rayN 类客户端，从剪贴板导入订阅即可。面板里的『帮助中心』也内置了图文教程，随时可查。」
- **字幕**：客户端 → 导入订阅 → 选节点 → 开启代理 ✅
- **时长**：40s

## 场景 7 · 其余用户功能速览（约 25s）
- **截图**：`user-orders.png` `user-points.png` `user-notices.png` `user-account.png`
- **画面**：依次快速切过四页。
- **操作**：左侧依次点「订单记录」→「积分明细」→「公告通知」→「账户设置」，各停留约 4–5s。
- **口播**：「其余功能一览：『订单记录』查历史购买；『积分明细』看积分收支；『公告通知』看站点公告；『账户设置』里可以改密码、绑定邮箱、管理登录设备。用户端到这里就全了。」
- **字幕**：订单 / 积分 / 公告 / 账户设置
- **时长**：25s

# 第二部分：管理端配置教程（约 3–3.5 分钟）

> 切换到管理员账号 `admin`。登录后左侧栏底部展开「管理后台」，分「运营 / 节点服务 / 内容系统」三组。

## 场景 8 · 管理概览（约 15s）
- **截图**：`admin-overview.png`
- **画面**：管理概览——用户数 / 流量 / 收入等统计与分布图表。
- **操作**：点「管理后台 → 管理概览」，鼠标扫过各统计卡与图表。
- **口播**：「管理员登录后，展开左下角『管理后台』。『管理概览』是运营总览：用户规模、流量消耗、收入趋势一目了然。」
- **字幕**：管理概览 = 运营数据总览
- **时长**：15s

## 场景 9 · 节点管理（约 35s）
- **截图**：`admin-nodes.png`
- **画面**：节点管理——节点列表、节点分组、外部订阅源。
- **操作**：点「节点管理」→ 展示已有节点（香港/日本/新加坡/美国/台湾）→ 点「新建节点」演示表单（类型 自建/外部、名称、协议、分享链接、所属分组）→ 讲「节点分组」：一个分组决定一批节点 → 讲「订阅源」：粘贴机场订阅自动拉取。
- **口播**：「先配节点。『节点管理』里可以手动新建节点，也能粘贴外部订阅链接批量导入。关键概念是『节点分组』——把节点归到不同分组，比如『高级线路』『标准线路』，稍后套餐会按分组授权。这样『买了哪个套餐、能用哪些节点』就由分组精确控制。」
- **字幕**：节点管理 → 建节点 / 批量导入 / 按『节点分组』归类
- **时长**：35s

## 场景 10 · sing-box 核心配置：出口与中转（约 40s）
- **截图**：`admin-singbox.png`
- **画面**：sing-box 配置页，顶部 Tab：TLS 配置 / 入站 / **代理出口** / **链路拓扑** / 配置预览。
- **操作**：点「sing-box」→ 依次点每个 Tab：
  1. 「TLS 配置」：添加 TLS/Reality 证书配置。
  2. 「入站」：配置对外监听的入站协议。
  3. 「代理出口」：配置流量的最终出口（直连或落地代理）。
  4. 「链路拓扑」：把「入站→中转→出口」串成多级中转链路。
  5. 「配置预览」：查看/校验生成的 sing-box 配置。
- **口播**：「这一页是核心。『TLS 配置』管证书与 Reality；『入站』是对外监听；『代理出口』决定流量最终从哪落地；把它们在『链路拓扑』里串起来，就能做多级中转——比如国内入口转到香港中转、再从落地机出去。改完在『配置预览』一键校验，避免配置写错。」
- **字幕**：sing-box → TLS / 入站 / 代理出口 / 链路拓扑 / 预览校验
- **时长**：40s
- **备注**：演示实例未预置证书/出口，页面为空态，讲解时说明「在这里点『添加』即可配置」。

## 场景 11 · 套餐管理（约 35s）
- **截图**：`admin-packages.png`
- **画面**：套餐管理——5 张套餐卡，每张标注 类型（计划/流量）、积分价、库存、订阅人数、流量/有效期/设备数、卖点。
- **操作**：点「套餐管理」→ 点「创建套餐」演示表单，重点讲三处：①「可用节点分组」= 买了给哪些节点（对应场景 9）；②「可购买用户组」= 谁能买（空 = 所有人可买）；③ 卖点、库存、排序 → 讲「上架/下架」与拖动排序。
- **口播**：「有了节点，就能配套餐。新建套餐时有两条最关键的绑定：一是『可用节点分组』，决定买了这个套餐能用哪些节点；二是『可购买用户组』，决定谁看得到、买得到——留空就是对所有人公开。设置好积分价和有效期，上架即可在商城售卖。」
- **字幕**：套餐管理 → 绑节点分组 + 限购用户组 + 定价上架
- **时长**：35s

## 场景 12 · 用户与用户组（约 25s）
- **截图**：`admin-users.png` `admin-user-groups.png`
- **画面**：用户管理列表 + 用户组页。
- **操作**：点「用户管理」→ 演示：新建用户、充值积分、「分配套餐」（管理员免费开通）、查看某用户订单/套餐 → 切「用户组」→ 讲用户组用于「限定套餐可购买范围」。
- **口播**：「『用户管理』里可以新建用户、充值积分，或直接给某个用户免费『分配套餐』做手动开通。『用户组』则和套餐配合，用来做分层销售——比如某些高级套餐只对特定用户组开放购买。」
- **字幕**：用户管理（充值 / 分配套餐）· 用户组（分层限购）
- **时长**：25s

## 场景 13 · 订单与注册码（约 20s）
- **截图**：`admin-orders.png` `admin-reg-codes.png`
- **画面**：订单管理 + 注册码。
- **操作**：点「订单管理」→ 演示查看订单、退款预览/退款 → 切「注册码」→ 演示批量生成注册码。
- **口播**：「『订单管理』能查看全部订单并做退款处理。如果站点采用邀请制注册，就在『注册码』里批量生成邀请码发给用户——这也是前面注册环节里那个注册码的来源。」
- **字幕**：订单管理（退款）· 注册码（邀请制）
- **时长**：20s

## 场景 14 · 证书中心（约 25s）
- **截图**：`admin-certs.png`
- **画面**：证书管理——ACME / Cloudflare DNS-01、粘贴导入、自签、续期、导出。
- **操作**：点「证书管理」→ 演示「申请证书」：选 ACME + Cloudflare DNS 验证 → 填域名 → 需要 Cloudflare API Token（讲一句权限：Zone.DNS 编辑权限）→ 申请 → 展示到期与「续期」。
- **口播**：「节点要走 TLS，就需要证书。『证书中心』支持自动签发：填好域名、用 Cloudflare 的 DNS 验证一键申请，到期还能自动续期。用 Cloudflare 需要一个具备 DNS 编辑权限的 API Token。」
- **字幕**：证书中心 → ACME + Cloudflare DNS 一键签发 / 自动续期
- **时长**：25s

## 场景 15 · 服务器与监控（约 25s）
- **截图**：`admin-servers.png` `admin-monitor.png`
- **画面**：服务器（多机 SSH 编排）+ 监控管理（探针面板/热力图/告警）。
- **操作**：点「服务器」→ 讲添加远程主机、测试连接、一键 rebuild sing-box → 切「监控管理」→ 讲探针上报的 CPU/内存/带宽热力图与告警阈值。
- **口播**：「轻舟支持多服务器。『服务器』里通过 SSH 纳管多台落地机，一键下发并重建 sing-box。『监控管理』则汇总各机探针数据——CPU、内存、带宽热力图，超过阈值自动告警。」
- **字幕**：服务器（多机 SSH 编排）· 监控（探针 + 告警）
- **时长**：25s

## 场景 16 · 系统设置 & 在线更新（约 30s）
- **截图**：`admin-settings.png` `admin-update.png`
- **画面**：系统设置（基础设置、面板公开地址、退款策略、首页、SMTP、ACME/Cloudflare、**订阅模板**、告警阈值）+ 在线更新。
- **操作**：点「系统设置」→ 重点展示：①「注册模式」开放/注册码/关闭 + 邮箱验证开关（呼应场景 2）；②「订阅模板」卡片——Clash 订阅模板自定义；③ SMTP 邮件；④ 面板公开地址 → 切「在线更新」→ 讲从 GitHub Release 检查并一键自更新。
- **口播**：「『系统设置』是全局开关：这里控制是否开放注册、要不要邮箱验证；『订阅模板』能自定义下发给 Clash 的规则模板；还能配 SMTP 邮件、退款策略、首页内容。最后，『在线更新』直接对接 GitHub 发布，检查到新版一键升级，不用登服务器。」
- **字幕**：系统设置（注册 / 订阅模板 / SMTP）· 在线更新（一键升级）
- **时长**：30s
- **备注（重要）**：面板一旦改过订阅模板，会永久覆盖内置默认模板；要恢复同步得清空输入框而非粘贴。

## 场景 17 · 内容：公告与帮助文档（约 15s）
- **截图**：`admin-announcements.png` `admin-help.png`
- **画面**：公告管理 + 帮助文档。
- **操作**：点「公告管理」演示新建/置顶公告 → 切「帮助文档」演示新建图文教程（对应用户端『帮助中心』）。
- **口播**：「最后是内容运营：『公告管理』发布站点通知，可置顶；『帮助文档』维护用户端『帮助中心』里的图文教程，比如各客户端的导入指南。」
- **字幕**：公告管理 · 帮助文档
- **时长**：15s
